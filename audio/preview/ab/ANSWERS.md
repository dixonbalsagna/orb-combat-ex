# A/B reels: the answer sheet

**Do not read this before you have listened to a reel.** Each reel plays the same two lines three times in the order below. A is the voice as it is today, B is Gemini's numbers, C is the hybrid.

| Reel | First | Second | Third |
| :--- | :--- | :--- | :--- |
| the Protagonist (`reel-protagonist.wav`) | B | C | A |
| the Rival (the Anti-hero) (`reel-anti_hero.wav`) | C | B | A |
| the Empress (`reel-empress.wav`) | C | A | B |
| the Cyborg (`reel-cyborg.wav`) | B | C | A |

- **the Protagonist**: A is `protagonist`; B is `protagonist_b` (B: Gemini's numbers (bouncy, short)); C is `protagonist_c` (C: hybrid (a little shorter, same chat)). Lines: "Good. You came. Now show me everything." / "Ha! My arm. I'll need that later."
- **the Rival (the Anti-hero)**: A is `anti_hero`; B is `anti_hero_b` (B: Gemini's numbers (clipped, staccato)); C is `anti_hero_c` (C: hybrid (faster, a little higher, still low)). Lines: "You were adequate. That is the highest thing I say." / "Fifth. Behind the goons."
- **the Empress**: A is `empress`; B is `empress_b` (B: Gemini's numbers (drawl, chorus, booming laugh)); C is `empress_c` (C: hybrid (overlap, shimmer, two laughs)). Lines: "Ohoho. Cute. Cute! ...Filed under Cute." / "Gahaha! Bring me their roof, my petitioners. We are not amused."
- **the Cyborg**: A is `cyborg`; B is `cyborg_b` (B: Gemini's numbers (growl and blip, lurching, crush and comb)); C is `cyborg_c` (C: hybrid (growl and blip, lurching)). Lines: "Sensors say crunchy. Tenderising now." / "Protein. More protein! I can smell the marrow in your chassis."

B's bus chain (chorus, reflection, crush, comb) is approximated by baked versions made by our own code, because a headless run cannot run the engine's live effects; the real chain would be judged on the web build with a window open.
