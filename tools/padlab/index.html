Pad lab

A small page with no fight in it. It reads what your thumbs do on a gamepad and saves the numbers to a file on this computer.

Nothing is sent anywhere: this page makes no network requests, and the only file written is the one you save yourself.

Keyboard: press Space to start a step, and Space again for the next one, so you can run the whole thing with your other hand. Esc cancels the step that is running. If no pad shows up, press any button on the pad once (Chrome hides a pad until its first press).

1. Every pad the browser reports

All slots are shown, even empty ones and ones a game might skip. The bars move live. Left stick is axes 0 and 1, right stick is axes 2 and 3.

2. Is there a phantom pad?

A phantom is a hidden or virtual pad (a second controller entry from Steam Input or a driver tool) that can hide the real stick from a game. Two checks: the idle test (steps 1 below) and the live highlight on the pad cards above, which names the pad that really changes when you push a stick.

    4. Save profile

    Saves a small JSON file with the pads seen, what the phantom check found, and the numbers for each stick you measured, plus suggested values in the game's units. It goes to your browser's Downloads folder, and a copy is kept in this browser's storage.
