# QA's civilians-removed run: a setup key (World, 2026-11-02)

Legal's RL-244 condition 4 (and RL-215 to RL-217): the civilians-removed run is repeated on the new base (the places reached), and must show the same anguish effect from buildings alone. QA needs a switch that removes the civilians in the sim. The EP: park one, off by default, a setup key.

**The key:** `"civilians": false` in a match's setup (default true: no key, or true, is today's match, byte for byte). It is read where the planet's world is made (`WorldPlanetWorld.gen`, World's), so it needs **no change in Simulation's files**; the setup is in the replay header, so a replay of such a match carries the key. It applies to a match on a planet (`planet` in the setup, gen 2 or 3), including the far places' people when `plans.farPeople` is on; the hand-made world (no `planet` key, Simulation's `terrain.gd`) is not covered: QA's civilians-removed run is on planets.

**What it does** (`WorldCollateral.removeCivilians`, called right after the collateral state is built): every building's people, its alive count and its flight record are zero, and the lure histogram is empty, so nothing that reads people (a casualty, an evacuation, a lure, the meters those feed) has anything to read. **`pop0` and `present` stay what they were**, so the meters' scale and the collateral budget's basis are the same as in the match with people: **the two runs differ only by the people**, which is the point of the run.

**Proved:** `CIVILIANSREMOVED` 0 failed (planet 7, everywhere on and far people on): with the key absent or true there are 8,955 people and the match is the same one (same state hash); with `false` no building holds a person (first ring and far places), the histogram is empty, `pop0` is 1,799 as before, the 3,899 buildings and the ground are the same; a blast over the town takes no one (0 lost, 0 fled) where the same blast in the run with people takes 36 and sends 160 fleeing.

**What QA does with it:** run the same seeds with and without the key and compare the hero's anguish and the structures lost; the director's choices that read people (RL-214 left the personality terms in: a launch's landing score and `popNear`) will differ, since there is no one to read: that difference is what the run measures.
