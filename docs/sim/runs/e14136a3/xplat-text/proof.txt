1. Windows Godot's printf rounds an exact half away from zero; glibc and musl (Linux CI, the web build) round it to even (fmt.gd.txt):
   "%.1f" % 0.25  -> Windows 0.3   Linux 0.2
   "%.1f" % 12.25 -> Windows 12.3  Linux 12.2
   "%.2f" % 0.125 -> Windows 0.13  Linux 0.12
   "%.0f" % 2.5   -> Windows 3     Linux 2
   (every non-half value prints alike)
