Combat and Choreography, cloud session. Brief: `docs/ep/cloud-briefs/combat-moveset-generator.md`. Branch: `cloud/combat-choreography/movegen`, from origin/main `9631fc7`.

## SUMMARY

The generator is now `tools/movegen/`: Node with no dependencies, a function-for-function port of Combat's reference `gen_moveset.py` (version 21), plus a pool exporter, a coverage report, a names screen, proposals and schemas. It writes the build's files byte for byte as the reference does: on the committed lock, on a full `--relock`, and on the nine-fighter roster folder. Its 40 tests pass, and so does every gate. Every piece of the two built fighters' 17 brawl pools in `data/combat/recipes.json` is generated, in the same order. What it can't express is named in `coverage.md`. The Prodigy and the Colossus are generated as templates for Orb in `docs/combat/proposals/`. Nothing in `data/` changed.

## DECISIONS

- **A port, not a rewrite.** Combat's Python had 21 versions of rulings in it. Porting it function for function made "same output" a testable claim, and it holds byte for byte. Node was chosen because every gate and CI job is Node, and Orb's PC and CI are not known to have Python. The Python stays as the reference, and the tests compare the two whenever `python3` is present.
- **One deliberate change.** The proof that four point-blank bolts can make a mashed run of 30 under e09 is a budgeted search ordered by a hash of the fighter's key. For the key "prodigy" the search ran out on bolts the rival passes with, so a run existed but the check said it didn't. The port now tries up to seven more keys. Only that verdict can change, never a move, and the build's files are unchanged.
- **The names screen reads Legal's files in place.** It reads e11/e14, `never-use-words.md` and stage 0 of `name-screening.md` each run. Copying those words into Combat's data would put franchise words in a design file. A source that yields no words fails the check, so a rewording can't let the screen pass silently.
- **"ball of the foot" is allowed** in a heavy's plain name: it names the foot tip (anatomy), not a technique built on "ball" (e11). The allowance is data with its reason, and it waits on Legal (below).
- **Pools are written by rules in `cells.json`.** A pool row is a move whose key set plays as it is (level `posed` or `stand_in`). Hand-state swaps and re-aims wait for Animation's derivation, which is what the live file does. The rules reproduce all 17 brawl pools of both fighters in order. The only extra pieces come from packs `rival9` and `protag12`, which the live recipes predate.
- **The older pools are not generated.** blur.*, combo.* and power* are hand-kept tables from before the generator. `coverage.md` lists each piece in them the generator doesn't give, with the reason: his never row (the rival's palms and blade-hand mediums, which Orb's split took away), another key set already reading the shape, no key set (the tail strikes), or not picked.
- **The proposals are the Prodigy and the Colossus.** They are the first two in Game Design's build order and two of Orb's four chosen niches. Both are laid over the rival's row and borrow only common pieces, as the roster sketches do. Both reach the gate's quarter (26% and 29%). Their titles are Narrative's placeholders.
- **Schemas live in `tools/movegen/schemas/`, not `tools/schemas/`.** The validator's self-test wants every schema there mapped to a `data/` path, with fixture cases. Nothing these schemas describe is under `data/` yet, so moving them is Tools' step when the movesets land.

## RISKS

- **Parity rests on the Python reference's behaviour,** including its float sums. Python 3.12 changed how `sum()` adds floats; that touches only the gate's printed percentages, never a file. A float written as `3.0` would come out of the port as `3`; no output holds a float today, and the test would catch one.
- **Proposals hash their merged identity in the port's JSON text.** Their `inputs` lines are the port's own, which is fine while the port is the tool.
- **The names screen parses Legal's prose.** If Legal rewords the e11 sentence, the screen fails loudly rather than silently. It doesn't keep working.
- **`coverage.md` compares with `data/combat/recipes.json` as it stands.** When Encounter lands the split recipes, the coverage table changes with them; `--check` fails only if a live brawl piece goes missing.
