# Done tests: one line for each Alpha feature

**Status: draft for the Executive Producer's page** (row A-PROCESS-16, a supported row: Production Operations drafts it, the EP owns and commits it). Written 2026-11-13. Taken from the exit criteria X-01 to X-34 (docs/ep/alpha/alpha-audit-specification.md, section 4.2) with the changes the path to Alpha proposes (04-path-to-alpha.md, "Exit criteria this audit proposes to change"). Where a line carries "(proposed)", the path's change is not yet confirmed by Orb and the specification's wording stands until it is.

**What "done" means for a feature:** its done test passes on a commit, with the result saved under docs/*/runs/<sha>/ (the project's rule, CD-22). A feature called done on a document's word is not done. "First reading" means a failing number is the expected result in that milestone; "must pass" means the milestone cannot close without it.

**Not here:** the register rows (milestones.md and milestone-rows.md say which row closes when) and the criteria that belong to the EP's process only. The planet-size scope Orb added on 2026-11-13 has no X line yet; see "Gaps" at the end.

## Gaps in this draft (for the Executive Producer)

1. **The added planet scope has no done test.** Orb asked on 2026-11-13 for five planet sizes, terrain, destruction and clipping toward A1. X-11 (as the path proposes it) says "a seed and three dials at today's one size", which the five-size scope overtakes. A done test for each is needed; the sprint plan's own words are the starting point: each size generates, plays and holds the shipped quality on Orb's PC, with its frame cost read in a quiet window; fighters' feet meet the drawn ground; no fighter sinks into a crater or building; buildings break at every tier without the rebound Orb saw.
2. **The stamina, energy and body loop (decision 11) is covered only through X-15 and X-13.** If Orb wants a separate "feel" test (for example, injuries worsen at low stamina as Orb described), Game Design writes it in the model page.
3. **"Marks drawn on the fighters"** (Orb's answer 12: placeholders for in-world auras and glows) is a look question, read by the look gate, not an X line.
4. **A feature with no X line** (for example, the quit row, or the fighter pick) closes through register rows (A-MODES-06, A-MODES-11) and X-05's smoke run; no separate line is drafted.
