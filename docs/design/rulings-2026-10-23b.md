# Rulings, 2026-10-23 (second file): Combat's biome layer

Owner: Game Design. **One decision per item, routed by owner.** Paper only; every number is a first value. It answers Combat's `docs/combat/biomes.md` §6, with its parked data in `docs/combat/pending/biomes/`, all behind switches. **Keyed by Combat's provisional biome names** (jungle, savanna, tundra, taiga, wetland, coast, highland, volcanic, the ice sheet and sea ice) and surface classes. A World rename is a key change, not a new ruling.

**The rule over all of it,** Combat's own §1, confirmed: the ground changes distances, looks and the world, and never when a press is taken. Where a proposal moves control, it is ruled below so it keeps to that.
