# QA's rows: launch anywhere, the hero's forms and the run (2026-10-17)

Owner: Game Design. One list for QA, gathered from the pages that rule them. **Every bound is a first value.** "Hard" means a test that must pass every time; the rest are bands read over matches. Where a row says "the route", it is QA's route script (B at every opening) against the medium AI. Read on 200 matches where a row is near its edge.

## 3. The run (`run-mode.md`)

**Hard tests**

| # | Row |
| ---: | :--- |
| R1 | A building marked, breached or downed in a fight is in the same state when a later slice crosses it |
| R2 | A fight replays bit-identical from its header alone |
| R3 | The run state at a fight's start is the one the last fight ended with |
| R4 | A retry starts from the same run state and seed as the fight it retries |
| R5 | Every fight starts from base form, at power 0 |
| R6 | The player never climbs past the run's ceiling, and a form boon raises it one tier |
| R7 | Every boon offer holds a form while one is still locked |

| R10 | The boss path is one a run, and the same for the same history |
| R11 | No offer touches down in a fallen place, and no fight starts with a fighter in a crater or under water |
| R12 | No offer, beat or card names a school, a hospital or a place of worship as a target |
| R13 | The planet's ceiling: people lost before the boss at most 40%; by the end at most 70% |
| R14 | A score, achievement, unlock, title or challenge that counts a death: none |
| R15 | Each catastrophe effect's worst-case clips, both modes, in the darkened sky: pass the flash check, red flashes 0 |
