A gate is green only with its record; "I think so" is red. If a gate cannot be made green, Legal says which part of the plan changes, not that the gate is waived.

**Where testers' raw files live (RL-267).** A tester's raw files (report files, logs, clips, screenshots, replays, anything that came from their PC or names them) are kept **only in a git-ignored folder on Orb's PC**: `.private/testers/` (the `.private/` folder is already ignored by `.gitignore`). They are never saved under a tracked `docs/*/runs/` folder, never committed, never pasted into a row, brief or report, and never put in the scratchpad of a session that is later committed. What may be committed is a **summary with no tester name, no account name and no path**: counts, findings, severities, build ids. Without this the promise to delete a tester's reports on request cannot be kept, because git history cannot be cleanly emptied once a file is in it. A tester is "a named friend" or an id such as T1, with the key list kept privately by Orb.

**Two rules that keep the list honest.**
1. A gate is never marked green on a wording ruling alone when it needs a measurement (G4, G13, G21) or a run (G1, G3).
2. Nothing in this list changes what Orb and Orb 2 may play; it holds only the files outside friends receive.
