## What this replaces, and where it goes (for Tools, through the EP)

Today the package text step reads `tools/site-interim.json` (or `site-interim-owner.json`), a notice written for the public web page and tied to RL-161's delegation, which ends on 2026-11-15 and is not wording Legal read for tester downloads. This page is the tester package's own notice. Tools places it as a new notice file, `tools/site-tester.json`, with the same shape (`draft: false`, `title`, `gate.heading`, `gate.blocks[].p`, `gate.under`, `gate.ai`) plus a new `tester` list for the extra sections below, and points `activeNotice()` at it for tester packages. Words that are already fixed in code (`PRIVACY`, `WINDOWS_WARN`, the RUN steps, `NO_ASSURANCE`) are not changed here; this page adds sections and uses those fixed sentences unchanged. The package check must never find the words safe, tested, verified, virus-free or compliant; none is used below.

## NOTICES.txt

Stays generated from `tools/site-licences.json`, as `noticesText()` does today (the Godot MIT text, the Open Sans OFL text, the engine's other components and their license texts), so it always matches the About screen. Legal adds one **header paragraph** above the first section:

"This file holds the license and copyright text for the third-party software this game contains. They apply to those parts only. The game's own code, art, writing, sound and name are not under any of these licenses: all rights in them are reserved by their owner."

Rules: (1) no music file ships in a tester package until it has its own row in `asset-origins.md` and a separate notice under `suno-music.md`; until then the package says nothing about music. (2) Any new third-party component in a build needs a `licence-register.md` row first, and Tools regenerates the file from the licences list. (3) The text is American English, with official spellings for licence names ("MIT License", "SIL Open Font License 1.1").
