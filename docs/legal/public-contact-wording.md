# A way to reach the project: wording for the public pages (CD-02, RL-256)

Legal, 2026-11-07. Audit finding F-02 / AC-212: no contact route exists on `/`, `/play/` or `/about/`, so a player, a rights holder or anyone affected has nowhere to write. A screen, not legal advice.

## The route

The project's public GitHub Issues page: `https://github.com/dixonbalsagna/orb-combat-ex/issues`. Checked 2026-11-07 with the GitHub API: the repository is public and Issues are on. It needs no email address, no account of Orb's and no spend, and it is the one route that works today.

Two limits, stated plainly so nobody oversells it:
- **It is public.** Anyone can read what is posted. The wording below tells people not to post personal details, and to say if they need a private reply.
- **A reader is named (2026-11-07):** the EP reads the Issues page daily while any public page is up. If that stops, the route is withdrawn from the pages rather than left as a label with nobody behind it. Orb may later add a project-only mailbox; that is Orb's choice and not needed for this fix.

## The words (American spelling, plain, no promises we cannot keep)

**Short form, for the footer of `/`, `/play/`, `/about/` and the offline notice:**

> Questions, problems or requests (including a request to take something down): open an issue at github.com/dixonbalsagna/orb-combat-ex/issues.

**Long form, for `/about/`:**

> **Contact.** This is a small free project. To report a problem, ask a question, or ask us to change or remove something, open an issue on our public GitHub page: github.com/dixonbalsagna/orb-combat-ex/issues. Issues there are public, so please do not post personal details. If you need a private reply, say so in the issue and give no more than that; we will answer there and suggest a way. If a scene in the game bothered you or made you unwell, stop playing and tell us what you saw so we can fix it.

**Engine line (CD-08, same page):** replace "Godot Engine 4.7.2-stable (official)" with "Built with the Godot Engine (version 4.7.2), in a custom web build." The word "official" is not true of a custom build.

## Rules for using these words

1. The address is the Issues link and nothing personal: no email of Orb's, no real name, no street address, no phone (CD-07, Orb's ruling on personal details).
2. A request to take something down is read the day it is seen and, if it names a person, a brand or a copyrighted work, is passed to the EP and to Legal; nobody replies with an admission or a promise on the issue itself (stop, do not argue, tell the EP, as `licence-recommendation.md` section 5 says).
3. The offline notice carries the short form too, so the route survives a take-down.
4. Tools' public-words scan covers the new strings (the link must match `site-url-words.json`; add it if the scan flags it).
5. If the repository is ever made private or Issues are turned off, this wording is withdrawn at once and the pages carry another route.
