# May a key-only itch.io page exist under the working title before the paid title search? (A-LEGAL-09, RL-261)

Legal, 2026-11-13, written against def3445a. A screen, not legal advice. Orb's decision 9 hangs on this.

## The question

Orb Combat EX is a working title with an open name clash: a small unregistered GPL project called OrbCombat uses a near-identical name in the same engine (name-screening.md, RL-024). The formal search (US, EU, UK, Japan; classes 9, 28, 41) has not been paid for. `name-screening.md` said no store page, itch.io page or promotion before that search. May a **restricted, key-only, unlisted, unpromoted** page go up first, for a handful of named friends?

## The ruling: **yes, on conditions**

The risk in a name clash comes from using the name in public trade: listing, promotion, selling, being found by people who are looking for the other thing. A private page that only named friends can open, that sells nothing and that nobody can find uses the name the way a private folder does. If the name later changes, the only cost is renaming one page. So it is acceptable now. A store page, any promotion and any sale still wait for the search.

**Conditions (all of them):**
1. **Restricted and unlisted.** The page's visibility is "Restricted", with downloads behind keys. It is not public, not in itch.io's browse or search, and not linked from any public page, repository page, README, social post, video or Discord invite.
2. **Unpromoted.** No announcement, devlog, tweet, trailer or mention anywhere. No cover image or screenshot of in-progress character art (Orb's standing rule), which means a plain text cover or a still with no characters.
3. **Marked as a working title.** The page title reads "Orb Combat EX (working title)" and the first line of the page says the name may change.
4. **The AI disclosure is on the page**, up front, in the fixed wording (page-fixed-lines.md).
5. **Free, nothing sold.** No price, no tip jar, no ads, no pay-what-you-want. A download key is not a sale.
6. **One key per named friend,** adults only, each told in the plain words of the tester note. The list of who has a key is kept privately by Orb, never in the repository.
7. **No other use of the name.** Nothing registers a domain, a store handle, a shop name or a trademark, and the page's address uses the working title only.
8. **Nothing on the page claims the name is cleared.** Wording like "official" or "™" is not used.

**What ends it (the page goes to the neutral name or comes down at once):**
- Anyone contacts Orb about the name (the other project's author, or anyone else).
- The paid search, when it happens, finds a conflict.
- The page is found by search engines, linked from anywhere public, or a key leaks.
- Orb wants to list, promote, sell, or open the page to the public.
- A tester reports they could not tell this game from another.

**If it ends,** the page title changes to a neutral label that is not a name: "Private fighting-game test build". That is a plain description, not a brand, so it needs no screening. Orb picks a new name later; any new name is screened (RL-024's procedure) before it goes on the page.

**What still waits for the paid title search:** any public or listed itch.io page; any Steam page or Steamworks fee; any promotion, trailer, press or social post using the title; any domain, handle or shop name; any sale or tip; any trademark filing. The search remains Orb's spend decision (CD-06) and is not brought forward by this ruling. If Orb wants the paid search sooner, that is a question to Orb on its own.

"May the private, key-only itch.io page go up under the working title 'Orb Combat EX (working title)' before the paid title search, if it is restricted, unlisted, unpromoted, free, with one key per named friend, and goes to a neutral name if anyone objects or the search finds a conflict?
