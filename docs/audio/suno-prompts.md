# Suno prompts: paste-ready blocks

Owner: Audio and Music. 2026-10-04. Companion to `suno-direction.md`, which explains the sound, the verified and assumed facts about Suno, the hand-back and the decisions I need from Orb. Read its section 1 first. **These blocks are generated by a script that checks every limit (style under 1,000 characters, exclude under 1,000, structure under 5,000), so the counts below are exact.**

## How to use a block

> **A note for Orb:** generate and download on the **paid plan**, within the monthly download cap (Legal, `docs/legal/suno-music.md`). Optional: a melody you hum, sing or play and upload as the audio input would give the main theme a human-authored core.

1. In Suno, open **Create**, choose **Custom** mode and the model **v6** (use **v6-wild** only to explore, never for a final).
2. Paste the **Style of Music** text. Paste the **Exclude** text into the Exclude field (Advanced Options). Paste the **Structure** text into the **Lyrics** box. Leave the title as the block's cue id and slug (for example `M02 fight-1`).
3. Switch **Instrumental** on if the page has that switch. The text already says instrumental and the exclude list says no vocals, so it works either way.
4. Set the sliders as the block says. **Variety 0** stops v6 rewriting our style tags while we are fixing the sound; raise it to about 25 once a block works, to get alternatives.
5. Upload the reference file(s) listed for the block (the **Audio** upload). The **Audio Influence** slider appears when you do. Our reference files are in `audio/preview/` and `audio/preview/suno-reference/`.
6. Make at least two takes of each block and listen to both before judging (Suno's own testers say take-to-take variation can be larger than a prompt change). Pick the take that has the right **tempo and key** first, then the best feel.
7. Download the WAV of the best take(s) and drop them into `audio/music/incoming/` as `suno-direction.md` section 6 says. Save the exact prompt and settings next to them (a text file with the same name).

**Tempo and key are the hard rule for the fight ladder (M02 to M05, M06, M07):** they must share 180 BPM (or 90 for M07) and the key of E, so the game can crossfade on a bar line. Suno does not obey a BPM exactly, so choose takes that land within about 2 BPM of the target; `node audio/tools/music_check.mjs FILE.wav --bars 32` tells you the tempo and the loop points.

## If a block does not work

| Problem | Try |
| :--- | :--- |
| It sounds spooky, dark or hollow | Check the exclude text went in. Add "bright, cheerful, sunny" to the style prompt. Lift Style Influence to 85. Make sure the reference upload is the riff clip and not the old `sketch-b` or `sketch-c` files |
| It adds vocals or choir | Say "no vocals, no choir, instrumental only" again in the style prompt and in the structure tags. Make sure Instrumental is on |
| The tempo is wrong | Put the BPM first in the style prompt, add "steady tempo, metronomic", lower Weirdness to 25, and try two more takes |
| The hook is lost | Raise Audio Influence to 65 to 75, and upload `sketch-a-town-band.wav` alone |
| It is too busy or muddy | Cut instruments from the style prompt (keep guitars, drums, tuba, trumpet) and shorten the prompt |
| It will not stop or loop cleanly | Ask for "ends on a full stop, no fade-out" and give us the whole file: we choose the loop points |
| The jokes disappear | Keep the "tuba oompah march break" in the structure tags; lower Weirdness rather than raising it |

## Free of names
