# mixed-schema (Tools, 2026-11-01): the schema, map row and cases for Combat's mixed string

`git -c core.autocrlf=false apply docs/tools/pending/mixed-schema/mixed-schema.patch` (3 files: `tools/schemas/combat-mixed.schema.json` (new), `tools/schemas/map.json` (the row `data/combat/mixed.json`), `tools/fixtures/cases.json` (8 cases)). **Lands WITH `docs/combat/pending/mixed-string/`**: its cases mutate the real `data/combat/mixed.json` that park adds, so on a tree without it the self-test fails.

The schema reads Combat's `mixed.json` as it is (all twelve keys required, closed except `_` keys): `enabled` (boolean), `windowTicks` (integer 1 to 1200), `tapMaxShare` and `edgeShare` (0 to 1), `burstBh`, `knockBh` (over 0, at most 20), `leanBh` (0 to 20), `wayReachBh` (over 0, at most 100), `wayEveryTicks` (integer), `wayForceMul` (0 to 10), `leadTicks` (exactly two integers 1 to 600; their order is the director's). Cases: a live-valid one, a bad version, a stray key, `enabled` not a boolean, `windowTicks` not an integer, `tapMaxShare` over 1, `leadTicks` with one number, `burstBh` 0. The ranges are from the live values (150, 0.34, 2.5, 0.5, 3, 4, 16, 1200, 1, [24, 110]); Combat may tighten them.

**Re-cut 2026-11-01 for Combat's current `mixed.json`:** two keys more, `arcMul` (E144: how much a low roof may raise the lob's arc; 1 to 10) and `freeBh` (E144: nothing stops the lob this near the thrower; 0 to 20), both required. Checked on a full HEAD export with this patch, `phrases-schema` and the current `mixed.json` and `phrases.json`: self-test 9,937 of 9,937, validate 0 errors. The two schema parks apply in either order. The stack leaves this one out while `combat-mixed-string`'s hooks conflict with main (sim/director/launch.gd).
