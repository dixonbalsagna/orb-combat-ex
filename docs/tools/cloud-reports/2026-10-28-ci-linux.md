## DECISIONS
- **Hash check against the same commit's project run, not a fixed hash.** The hash changes whenever gameplay changes. Comparing the binary with the project at the same commit stays valid on every commit and still proves the binary boots, loads its pck and plays the same match. The match with the committed Windows and web hash was checked by hand here.
- **The Linux template goes through setup-godot** (a new opt-in input), so the pin stays in one place.
- **Native Linux is the Deck default and Proton the fallback** (see steam-deck.md).
