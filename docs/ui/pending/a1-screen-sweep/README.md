# a1-screen-sweep: A-UI-09, a still of every menu and HUD state at 1280 by 800 and the smallest text on each (UI & UX, 2026-11-13; park, not landed)

`screen-sweep.patch` (`git apply`, three new files: `ui/tools/sweep.mjs`, `ui/tools/screen_sweep.gd`, `docs/ui/screen-sweep.md`; `git apply --check` clean on HEAD). **Apply after `a1-start-flow`** (its states use the A1 pages and the demo's `?modes`, `?quitrow`, `?mpick`, `?mquit`, `?mmid`, `?pquit` flags). Nothing here touches the game, the sim or any data.

How it works, what it covers and what it does not: `docs/ui/screen-sweep.md`. In short: `node ui/tools/sweep.mjs --dir <the demo's web export> --out <folder> --godot <exe> --tree <project>` runs the text pass headless (one Godot process) and takes each still through `tools/machine/capture.mjs` (one at a time); the table is `sweep.md` / `sweep.json`.

**First set (a scratch tree of HEAD def3445a plus the parks, `docs/ui/runs/def3445a/screen-sweep/`):** 24 states at 1280 by 800: the modes list (and mid-match), the setup for one and for two players, Quit's question, the single start card, the pause menu, the LAN pause, the new-match question, Quit's question over a match, the match-over card (and with a saved file), Settings (Rail and old card), the HUD in five mock scenarios, How to play and its About page, the feedback panel, the remap and the first-run notice. **No state has text under the 9 px floor or the 12 px aim (the smallest is 14 px, the UI's text floor), and none has a line off the screen.** That is the UI's own text only (not the world's labels or a window title). The committed folder holds the table and the six start-menu stills (no fighters); the other eighteen stills show the demo's grey-box fighters and stay on this PC, in the scratchpad's `sweep-out` folder (path in the report).

Needs: the demo's web export (Tools' build step; or the one-line scratch recipe in the report) for the stills; `--skip-stills` runs the text half alone. The sweep's states list lives in `screen_sweep.gd`: a new screen is one line there.
