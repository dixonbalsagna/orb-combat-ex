# a1-pause-clock: A-UI-01, the Rail's pause menu stayed off screen (UI & UX, 2026-11-13; park, not landed)

**Cause (settled on the real scene, `docs/ui/runs/def3445a/pause-clock/`).** The game holds the sim while the pause menu is open and advances the HUD by 0 (`render/core/main.gd`: `ui_hud.advance(0.0 if host.paused else delta)`). The Rail timed its slide-in and its lit bar on the HUD's own clock `_t`, which only moves when `advance` gets a positive step. So with the Rail on, the slide never left 0 and the rail and its cards sat off screen. The probe `ui/tools/pause_clock_probe.gd` (render/main.tscn, an AI match, pause opened as the game does) reads `slide 0.000` on all 60 frames before the fix. With Reduce motion on the slide is 1 at once (the cut), so the bug showed only with it off. My own stills missed it because the demo advances the clock itself. (The brief's two stills of a real Rail build cannot be made headless; the numbers above settle the cause, and the sweep's stills of the real game scene follow once Tools has a build to point it at.)

**Fix (ui/ only).** The menus have their own clock `_ut` in `ui_hud.gd`: it moves by the game's step when the game runs and by real time (the HUD's `_process`) when the game advances it by 0. The pause menu, the start menu, Settings and the lit bar's timers all read it. `advance_ui(dt)` is there for tests. Nothing writes the sim.

- `pause-clock.patch` (git apply; checked with `git -c core.autocrlf=false apply --check` against HEAD def3445a): `ui/hud/ui_hud.gd`, `ui/tools/hud_check.gd` (`_pause_clock_rules`), `ui/tools/pause_clock_probe.gd` (new).
- After the fix: slide 0.98 at the first frame and 1.0 from the fifth, Reduce motion off; 1.0 at once, on.
- Tests: `_pause_clock_rules` opens the pause menu the way the game does (advance(0.0) each frame): the rail slides in and settles, the lit bar slides, real time works through `_process`, Reduce motion cuts, and a copy with no menus clock stays at 0 (what Orb saw). Negative control: with the clock removed three of the new checks fail. Full hud_check, switch as shipped: 8293 checks, 0 failed.
