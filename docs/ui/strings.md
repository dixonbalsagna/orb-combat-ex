# Every player-facing string in ui/data, by where it shows

Generated by `python ui/tools/strings_inventory.py` (UI & UX, 2026-10-12) from `ui/data/*.json`. **826 strings in batches of ten**, one surface at a time, so Orb can mark a batch and Narrative can work from it. Ids, colours, notes and one-word identifiers are left out. The JSON stays the source: a rewrite goes into the data file named in the key column, and `hud_check` compares some of these word for word (the gate, the About page), so a change to those is made with its test. **Nothing new ships unmarked.**

Mark column: **keep**, **rewrite** (Narrative drafts), or **cut**. A flag in the key column (**N**) is a line Narrative's `docs/narrative/writing-quality.md` names.
