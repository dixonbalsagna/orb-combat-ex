# Special moves and energy attacks: Orb's idea sheet

This file is yours to write in. Rough is fine: a line or two in a field is enough, and any field can be left blank. Copy the blank card at the bottom once per idea. Nobody else edits this file; the EP reads it and turns each card into briefs.

Two rules, both short:

- Describe the move in your own words. Don't name another game, show or character here, even as a comparison; this folder is public. If a reference helps you think, put it in `.private/` (never committed) and write only what you want the move to do.
- An idea is not a promise. Every card goes through Legal's originality screen and Game Design's costs before anyone builds it.

## How to fill a card

Only the first three fields matter for an idea to be usable. Everything after that helps but can wait.

| Field | What to write | Choices, where there are any |
| :--- | :--- | :--- |
| Working name | Anything. Narrative drafts real names later and you edit them. | |
| Who | Which fighter, or "anyone", or a roster niche. | Protagonist, rival, Empress, Cyborg; speedster, stealth, heavy, terrain shaper, grappler, zoner, puppeteer, wildcard, juggernaut |
| The picture | What a viewer sees, start to finish, in a sentence or three. This is the heart of the card. | |
| Kind | The nearest family, if one fits. | Bolt, volley, charged shot, short beam, big beam, splitting shot, mine or trap, rushing strike, grab or throw, counter, guard or barrier, terrain move, summon or helper, transformation, something new |
| Where it sits | Stance and button, if you have a feeling for it. | Martial arts (nothing held), defensive (LB), energy (RB), charging (RT), manoeuvre (LT); X quick, Y strong, A context, B signature |
| Wind-up | What the fighter does before it comes out, and roughly how long the rival has to see it. | A blink, a beat, a long tell |
| How it travels | Straight, arcing, homing, splitting, hugging the ground, appearing at the target, staying on the fighter. | |
| When it lands | What happens to the rival: knocked back, launched, staggered in place, pinned, slowed, nothing but damage. | |
| What it does to the world | Craters, trenches, broken buildings, fire, water, nothing. How big, compared with a normal beam. | |
| How the rival answers it | What a good player does about it: block, dodge, hit first, reflect, outlast, run. | |
| Cost and limits | Ki, a cooldown, a wound it risks, only at a power tier, only once a match, only in the last acts. | |
| Speed, timing or holding | Does it change if the player mashes, times the press, or holds? | |
| Changes by place | Does it play differently over ocean, city, forest, desert, mountains, high up, or close to the ground? | |
| Who it belongs to | What it says about the fighter: a hero move that spares the town, a villain move that feeds on it, a show-off move, a desperate one. | |
| The feeling | One line: how it should feel to throw, and how it should feel to be hit by. | |
| Must not | Anything you already know it should never do or look like. | |
| Loose thoughts | Anything else. | |

## Worked example (one of ours, already in the game's plans)

- **Working name:** the splitting shot
- **Who:** the rival
- **The picture:** he flicks one bright shot off his fingers; halfway to the target it breaks into three that fan out and close back in from different sides.
- **Kind:** splitting shot
- **Where it sits:** energy stance, Y
- **Wind-up:** a beat; the hand comes up to the shoulder, open
- **How it travels:** straight, then splits and curves in
- **When it lands:** staggered in place if all three hit; chip damage if one does
- **What it does to the world:** small pocks where stray pieces land; a window or two
- **How the rival answers it:** dodge through the gap before it closes, or block and take the chip
- **Cost and limits:** a medium ki price; no cooldown
- **Speed, timing or holding:** held, the three become five
- **Changes by place:** over water the strays throw up spouts that hide the next shot
- **Who it belongs to:** a show-off's shot; he does not care where the strays go
- **The feeling:** thrown: effortless. Hit: surrounded.
- **Must not:** look like a ball held at the hand
- **Loose thoughts:** none
