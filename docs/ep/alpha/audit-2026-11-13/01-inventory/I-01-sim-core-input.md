## Notable

1. No CI job runs the 46 `sim/input/test/*.gd` scripts. No workflow references `sim/input`, and the only runner that looks there (qa/godot/pending-tests.js:145) wants `c<NN>_*.gd` files, which don't exist. The scripts only give manual lines (sim/input/test/aim_test.gd:5).
2. `SimKeyboard` has no code caller. Its only reference outside its own file is a comment at render/core/key_codes.gd:2. Keyboard input goes through SimLayout (sim/input/hub.gd:75).
3. `SimCampaign` is reached only through `checkArc` (sim/core/run.gd:391). No host code calls its episode API, and `fight/campaign.json` has `enabled: false`.
4. The menace and anguish meters (backburnered) are live code: sim/core/damage.gd:50-56 and sim/core/fighter.gd:686-705. Both shipped fighters' meters.json still define them (data/fighters/PROTAGONIST/meters.json, data/fighters/RIVAL/meters.json).
5. Ambush (backburnered) is still live: sim/core/hiding.gd:43 sets ambushUntil and sim/core/damage.gd:59 applies it. Full hiding is gated by kit.canHide (sim/core/fighter_data.gd:394).
6. The placeholder names KAI and VORR remain in the frozen JS core, sim/core/roster.js:5-6 (2 hits in test/frozen/golden-js.json).
7. The biome signature-variant name "HORIZON CLEAVE" is hardcoded in a test fixture at sim/core/tools/cross_check.gd:258.
8. In this slice, "strip" names the field world's line coordinate (sim/core/field.gd:177 `static func strip`), not the retired flat arena. I found no flat-arena code.
9. "Placeholder transform (ADR 0008)" is still in doc comments at sim/core/fighter.gd:568 and sim/core/fx.gd:185.
10. Most feel systems are off in data: brake, flight, forms, hitstop, kick, power, ricochet, cross, depth and campaign all have `enabled: false` (data/fight/*.json, data/combat/depth.json).
11. In data/input/timing.json switches, 13 of 25 flags are true, including rightStick, beamAim, quickRead, specialsOff, signatureRtOnly and stallKeep.
12. The camera's header names Camera as its owner (sim/core/view/camera.gd:5), but the path sits under simulation-engine's `sim/core/` (DIRECTORS.md:170).
13. sim/core/tools/parity.gd is 6,878 lines (98 funcs), the largest code file in the slice. It is the GDScript CI gate (ci.yml:191).
14. Touch and phone-vibrate paths are live (render/core/main.gd:1414, sim/input/haptics.gd:5) although mobile work is parked (ADR 0011). They are not new work, but they are maintained surface.
15. The only uncommitted item is the untracked probe `sim/input/tools/stall_probe.gd` (43 lines; header at :2 cites docs/controls/stall-keep.md).
