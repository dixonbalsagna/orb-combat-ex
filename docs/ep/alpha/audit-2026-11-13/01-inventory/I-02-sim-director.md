## Notable

1. Only 5 of 65 director tools run in CI: ci.yml:221, 229, 269, 403, 405. The rest are run only by an untracked local gate stack (e.g. docs/director/runs/20713b02/slip-arrive/sim_slip/gate_summary.txt:1-15).
2. The combat-parity frozen data (sim/director/test/combat-parity/*.json) is only checked by sim/director/tools/loader_check.gd:29, which is not in CI.
3. exchange.gd:1018-1035 holds a test-only hook (`checkData`) set by loader_check, inside shipped runtime code.
4. DirSwingRead has no runtime caller: swing_read.gd:5 says DirSwing asks it, but sim/director/swing.gd has no reference; only render/camera/tests/swing_read_check.gd:66 calls it.
5. stick.gd:5 says switches.rightStick is false; data/input/timing.json:41 has it true, so the stick path is live.
6. Placeholder finisher still in code: exchange.gd:808 and data.gd:665-678 ("generic.placeholder").
7. Backburnered hiding/ambush is live: ai.gd:108-111 (hidden, canHide), exchange.gd:331-335 (ambushUntil), brawl.gd:1387.
8. Backburnered menace/anguish meters are read: beam.gd:208, 245 (menace in beam power); beamplay.gd:508-513; location.gd:105.
9. Biome signature variants are live: sigafter.gd:1-4 reads data/combat/sigvariants.json, called from beam.gd:153.
10. brawl.gd is 4,305 lines, the largest file in the slice; zip.gd 1,649, launch.gd 1,383, exchange.gd 1,240.
11. No KAI/VORR names in sim/director (grep -w -i, 0 hits); no TODO/FIXME/HACK marks.
12. "strip" in launch.gd:70-91 refers to heightfield column caches, not the retired flat arena (read in context).
13. Many feature switches are off in data: chase, rally, recoilFlip, wallKick, water, outside, grapple, ending, calmTurn, cameraIntent, beamStruggle, stances, swing (data/director/interrupts.json, swing.json).
14. Five JS twins (ai.js, beam.js, exchange.js, launch.js, melee.js; 468 lines) are imported by the frozen JS core (sim/core/sim.js:12-13, sim/input/control.js:3-4, sim/core/damage.js:5-6) and run in the `sim` CI job (ci.yml:60).
15. Full copies of director files sit in docs/director/pending/ (e.g. docs/director/pending/grapple-g1/files/sim/director/grapple.gd), outside this slice, so class_name greps hit duplicates.
