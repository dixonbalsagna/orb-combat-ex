# Alpha audit, area 22: PROCESS (how the project runs)

Read-only review at baseline 8901d351 (game code of the build Orb played, 6a30b4c9). Reviewed 2026-11-13. Evidence is `path:line` on disk now, a CI run id (`ci:`), a commit (`commit:`) or a saved record. "(uncommitted)" marks a path listed in `../baseline-status.txt`. Machine-readable copy of the findings: `PROCESS.findings.json`.

## Summary

- **Works:** the landing gate with saved records per commit, the CI guards added after the 2026-11-07 audit, the daily watch on the public page (offline, confirmed daily), Orb's words kept verbatim, and a carefully written sprint loop.
- **Does not:** the planning paperwork. The risk register is the starting set from 2026-09-28, there is no backlog, no milestone tracker, no weekly token record, and the P0 to P5 roadmap no longer describes the project.
- **Biggest gap:** X-33 is not met. No change-control rule and no ideas log exist, while new ideas arrive weekly; and the project's state lives in one EP session and 14,805 uncommitted paths rather than in the repository.
