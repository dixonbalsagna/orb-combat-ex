# CODE: code health (Alpha audit, phase 2)

Read-only review at baseline 8901d351 (game code = 6a30b4c9, the last build Orb played). Nothing was run except read-only git, grep, wc and `gh run list`. "Main" means the committed tree; "Orb's build" means `homework/Files/builds/orb-first-play-6a30b4c9-6627cb9d/` (solo) and `orb-lan-6a30b4c9/` (LAN). A "switch" is one row of `tools/preview/switches.mjs`: a data key (or a page word) the private build turns on in a scratch copy. A "park" is unlanded work kept under `docs/*/pending/`. The "ratchet" is `tools/ratchet-two-fighter.mjs`, a count of places where code assumes exactly two fighters, which may only go down.

## Summary

- **Works:** CI is green on the commit Orb played (run 42722446938); the sim is held to its golden record, a determinism lint, a schema validator and the two-fighter ratchet; the last gate's records show no script error.
- **Does not:** the game Orb plays is not what main builds. At least 72 of 92 switch rows differ, the solo build also carries a scratch code patch, and the golden record and five gates only hold with the switches off.
- **Biggest gap:** F-CODE-01. Until Orb's configuration is the default on main, no commit is an Alpha candidate: every gate, CI run and desktop export measures a different game from the one being judged.
- Also: CI runs 116 of 262 check scripts; adding a third fighter still needs code (ratchet 365, flat since 2026-11-07); stamina does not exist in the sim.
