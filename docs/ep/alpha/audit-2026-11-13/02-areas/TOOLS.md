## Summary

- **No Windows program is ever started by CI** (F-TOOLS-13), although Windows is one of the two Alpha platforms.
- **The build-making tools are outside CI** (F-TOOLS-14): the LAN folder maker, the report folder and the browser smoke are run by hand only, and the smoke drives the menu by fixed screen points (it failed once on 6a30b4c9 when the start button moved).

Every release finding above touches one of them. Placed with tools-pipeline here by its charter (`tools/, build/, .github/`); the EP should confirm.
