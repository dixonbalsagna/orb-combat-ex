# PERF: performance and platform (Alpha audit, baseline 8901d351; game code of build 6a30b4c9)

Read-only review, 2026-11-13. Nothing was run in Godot or a browser; every line cites a file, a record, a commit or a CI listing. "Not evidenced" means no file or record settles it. RR-07's answer file was not there yet, so its reading was done here as far as the questions need (the table under Q2).

## Summary

- **Works:** the Windows preset exports and runs (a native reading on Orb's PC from 2026-10-27; the LAN program of 6a30b4c9 is made from it); the sim plays the same match on Windows, the web and a headless Linux binary; the wording for the unsigned-program warning exists; the one-click kit pattern was proven on a second PC.
- **Does not:** there is no desktop build of the solo game as Orb plays it, the desktop build workflow has never run, no Linux build has ever drawn a picture, and nothing has been run on a Steam Deck.
- **Not measured:** frame rate, loading and memory on the build Orb last played. The newest frame record of a whole match is from 2026-11-06, on the browser build.
- **Biggest gap:** the Alpha's two platforms (a Windows program and a Deck/Linux program with solo, couch and LAN play in one install) do not exist as a build anyone can make with one command (F-PERF-01, 02, 03).

**Q6. Running on the Deck: Linux build or Windows through Proton; how a tester adds it. Recommendation.** The project's standing advice is the native Linux build, with the Windows program through Proton as a fallback (`docs/tools/steam-deck.md:7`); the packaged README tells a Deck owner to "add it to Steam as a non-Steam game, or run it from Desktop Mode" (`tools/desktop-package.mjs:59`). Neither route has been tried on a Deck. Recommendation: keep native Linux as the Alpha build; deliver it through itch's app in Desktop Mode (it keeps the executable bit and handles updates, which a hand-unpacked `tar.gz` and the `chmod` line at `tools/desktop-package.mjs:56-58` do not for a newcomer with no keyboard), then "Add to Steam" once so it starts from Gaming Mode with the Deck's controls. This is a recommendation from the files, not a tested path; the first Deck session should try both itch's app and a plain download and write down which works.

**Q7. The minimum PC under ADR 0013: when does it get set?** ADR 0013 says only "before launch" (`docs/decisions/0013-no-laptop-target.md`, decision 3) and names no date, owner or method. Recommendation: not during Alpha. Set it at the start of Beta from the bench files Alpha testers send back (each file names the processor and graphics card, as the kit's file does: `docs/perf/oldpc/kit/run-test.template.cmd:38-46`), and publish it with the Steam demo page. Until then the Alpha notes should say "tested on these machines", not a minimum.

**Q8. Windows: what a tester sees with an unsigned game, and what the guide tells them.** The Windows preset has signing off (`export_presets.cfg:74`). Words exist in two places: the packaged README ("Windows may show 'Windows protected your PC' (SmartScreen): choose 'More info', then 'Run anyway'", plus Legal's fixed line that the file is unsigned and "If you do not trust the file, do not run it"; `tools/desktop-package.mjs:41`, `:51-52`), and the LAN folder's readme (`homework/Files/builds/orb-lan-6a30b4c9/READ ME FIRST.txt:18`). No tester guide exists yet to carry them. The program also shows the engine's default icon and no version text (`export_presets.cfg:76-80`), which makes the warning look worse. Signing is Orb's call (see Decisions).

## Gaps the questions missed

1. **One program or three.** Today the solo game (browser), LAN play (a patched Windows program) and the plain desktop package (no LAN, main's switches) are three different builds from three tools. Alpha asks for all eight modes from one menu on two platforms (X-05). Nobody owns joining them; F-PERF-01 and 03 are two halves of it.
2. **The desktop package forbids what the Alpha needs.** `desktop-builds.yml:9` and `:80` refuse a package that contains network code ("online play is out: the README's privacy line depends on it"), and `tools/desktop-package.mjs:43` says the game sends no data. LAN in the Alpha build needs that rule and that sentence re-ruled by Legal first.
3. **Reduce flashing is locked on in every desktop package** (`desktop-builds.yml:8`, `:77-78`).
