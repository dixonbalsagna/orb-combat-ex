# Alpha audit: the gap register

Judgment session, phase 3. Baseline 8901d351. One row per gap, merged from the 22 area reviews in `02-areas/` (343 gap findings became 270 rows; a gap seen from several areas is one row with several sources). The same rows are in `03-gap-register.json`, which also carries each row's source finding ids, the verifier's notes, and a flag for the one topic kept off Orb's page. `03-id-map.json` maps every area finding id to its row.

**Totals:** 29 blockers, 109 majors, 132 minors. Required for Alpha: 175; nice to have: 73; after Alpha: 22. Rows that change the sim's state hash: 50. (After the adversarial review nine rows changed: one made required, three re-costed or re-linked, the rest annotated; the JSON's `verify_notes` say what and why. No id changed.)

**How to read it.** Severity is after independent verification: every blocker and major was checked by a second agent told to refute it (`verified` yes); minors were sampled one in five in 18 areas and not sampled in ANIM, TEXT, ACCESS and AUDIO. Evidence strings are as the reviewers cited them, mostly `path:line` at the baseline; the table shows the first three, the JSON up to twelve, and the area file has the rest. Cost: S under 0.5M tokens of team work, M 0.5 to 2M, L 2 to 6M, XL over 6M; almost every basis is an estimate with no comparable, so treat a cost as a size class, not a quote. An id is never reused or renumbered after this file is handed over.
